## 🚀 快速开始

### 环境要求

- Python 3.8+
- pip 安装依赖

```bash
pip install pandas numpy matplotlib python-docx
```

### 数据准备

1. 前往 [阿里云天池 — UserBehavior 数据集](https://tianchi.aliyun.com/dataset/649) 下载 `UserBehavior.csv`
2. 将 CSV 文件放入项目根目录

### 运行步骤

按顺序执行以下脚本：

```bash
# Step 1：数据预处理（加载、采样、清洗、时间解析）
python "01_数据预处理.py"

# Step 2：行为概览分析（图1-4 + 统计指标）
python "02_行为概览分析.py"

# Step 3：转化漏斗、留存分析与用户分层（图5-8）
python "03_转化漏斗与留存分析.py"

# Step 4：自动生成最终 Word 报告
python "生成最终报告.py"
```

也可以跳过采样，直接在 `01_数据预处理.py` 中将 `USE_SAMPLE = True` 改为 `False` 使用全量数据（约 1 亿条，需较大内存）。

## 📊 分析内容

### 1. 数据预处理
- 读取约 3.4 GB 的原始 CSV 数据
- 支持随机采样（默认 100 万条）与全量处理两种模式
- 时间戳清洗与格式转换，提取日期和小时字段
- 过滤无效行为、异常时间戳与重复记录

### 2. 行为概览分析
- **行为类型分布**：PV、加购、收藏、购买四类行为的占比
- **每日趋势**：9 天观察期内 PV 与 UV 的变化趋势
- **时段规律**：用户 24 小时活跃高峰与低谷时段
- **用户活跃度**：人均行为频次分布及头部用户的贡献度

### 3. 转化漏斗分析
- **用户级漏斗**：浏览用户 → 意向用户（加购/收藏） → 购买用户
- **各环节转化率**：定位最大流失节点
- **购买行为分析**：购买用户中的加购/收藏比例

### 4. 留存分析
- **留存曲线**：以首日活跃日分群，追踪 0–8 日留存率
- **留存热力图**：各批次用户的完整留存矩阵
- **行为深度影响**：首日行为频次与次日留存的相关性

### 5. 用户分层（RF 模型）
基于 R（最近行为距今天数）和 F（行为频次）将用户分为四类：

| 分层 | R 值 | F 值 | 运营策略 |
|------|------|------|----------|
| 高价值用户 | ≤ 中位数（近） | ≥ 中位数（高频） | VIP 维系 |
| 浅度/新用户 | ≤ 中位数（近） | < 中位数（低频） | 新手引导、激活 |
| 沉睡用户 | > 中位数（远） | ≥ 中位数（高频） | 召回推送 |
| 流失用户 | > 中位数（远） | < 中位数（低频） | 低成本召回或无扰 |

### 6. 自动报告生成
- 基于 `python-docx` 自动生成含封面、图表、数据的完整 Word 文档
- 指标自动填入报告模板
- 输出 4 条运营策略建议，每条附带目标人群、问题分析、具体措施与衡量指标

## 📝 数据说明

- **数据集**：淘宝用户购物行为数据集（UserBehavior）
- **来源**：[阿里云天池](https://tianchi.aliyun.com/dataset/649)
- **时间范围**：2017-11-25 ~ 2017-12-03（共 9 天）
- **数据量**：约 1 亿条行为记录，约 100 万随机用户
- **字段**：`user_id`, `item_id`, `category_id`, `behavior_type`, `time_stamp`

行为类型（`behavior_type`）：
- `pv` — 浏览（Page View）
- `cart` — 加购（Add to Cart）
- `fav` — 收藏（Favourite）
- `buy` — 购买（Buy）
